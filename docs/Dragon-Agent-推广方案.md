## 一、收入模型拆解

日充值 ¥10,000 = 月流水 ¥300,000

### 1.1 付费点设计（充送模型）

核心原则：充 200 送 100，确保毛利覆盖 API 成本。

| 档位 | 充值金额 | 赠送金额 | 到账余额 | 赠送比例 | API 成本 | 毛利 | 日销量目标 |
|------|---------|---------|---------|---------|---------|------|-----------|

| 入门档 | ¥100 | ¥15 | ¥115 | 15% | ~¥38 | ¥62 (62%) | 35单 = ¥3,500 |
| 主力档 | ¥200 | ¥40 | ¥240 | 20% | ~¥80 | ¥120 (60%) | 15单 = ¥3,000 |

**日均 93 单 ≈ ¥10,000**。所有档位毛利 ≥ 58%。

> 充 50 送 5，充 200 送 40。赠送比例随充值递增，但全部保守，高价模型也兜得住。

### 1.2 定价逻辑

- 单次视频生成 API 成本：¥1-3（T2V 便宜，R2V 贵）
- 卖给用户 ¥3-5/次（余额扣费）
- 充 200 送 100 → 用户得 ¥300 余额 → 实际成本 ~¥100
- **每 ¥200 充值，毛利 ¥100**

> 不做纯按次卖，一定要充送——用户觉得占了便宜，API 成本也兜得住。

### 1.2 用户价值公式

假设每个视频生成成本 ¥1（API 成本），定价 ¥3-5：

> 日活用户 × 付费率 × ARPU = 日充值
>
> 目标：500 DAU × 8% 付费率 × ¥25 ARPU = ¥10,000
