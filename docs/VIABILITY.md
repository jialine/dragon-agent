## 2. 商业模式分析

### 2.1 收入模型

```
Dragon Agent (免费 Editor)
       ↓ 深度绑定
AgileMind Engine API (Token 付费)
       ↓ 
122B MoE 推理集群 (自有硬件)
```

**两层收入：**
1. **Token API 收入**（主收入）：按量计费，¥3-8/1M tokens
2. **B 端增值**（溢价收入）：企业私有部署、行业定制、SLA 保障

### 2.2 单节点单元经济

| 指标 | 数值 |
|------|------|
| 硬件成本 (4节点集群) | ¥15,000 (一次性) |
| 功耗 | 638W |
| 月电费 | ¥367 |
| 生成速度 | 33.5 tok/s |
| 月产能 (85% util) | **73.8M tokens** |
| 可服务轻量用户 | ~60 人/节点 (40K tok/天/人) |

### 2.3 定价与盈亏

| 定价策略 | ¥/1M tokens | 月收入/节点 | 月毛利/节点 | 硬件回本 |
|----------|------------|-----------|-----------|---------|
| 对标 DeepSeek | ¥1.0 | ¥74 | **亏损** | — |
| 性价比 | ¥3.0 | ¥221 | 亏损 | — |
| **中端定位** | **¥5.0** | **¥369** | ¥2 | 7,367 月 |
| **推荐：差异化定价** | **¥10.0** | **¥738** | **¥371** | **40 月** |
| 高端 (256K独有) | ¥20.0 | ¥1,476 | ¥1,109 | 14 月 |

> ⚠️ **关键发现**：按纯 token 售卖，¥5 以下无法盈利。必须通过差异化 (256K 超长上下文 + 多模型陪审团 + 辩论) 支撑 ¥10+ 定价，或走企业 B 端高客单价路线。

### 2.4 硬件成本碾压

| 方案 | 硬件 | 成本 | AgileMind 倍数 |
|------|------|------|:--:|
| 企业级 | 8×A100 80GB | ¥800,000+ | **53x** |
| 企业级 | 4×H100 80GB | ¥1,200,000+ | **80x** |
| 云 GPU | 8×A100 (租) | ¥15,000/月 | 月费=硬件价 |
| **AgileMind** | **4×消费级 16GB** | **¥15,000** | — |

这是最强壁垒——用 1/50 的硬件成本提供同等能力。

## 4. 风险分析

### 4.1 🔴 高风险

| 风险 | 详情 | 缓解 |
|------|------|------|
| **单节点产能瓶颈** | 33.5 tok/s，仅服务 ~60 轻量用户 | 多节点扩展；2.5G 网络支持 10+ 节点 |

## 7. 结论

### 可行性评级：⭐⭐⭐⭐ (可行，定位调整后更强)

**核心修正：**
| | 修正前 | 修正后 |
|------|---------|---------|
| 定位 | 零幻觉 AI 员工 | **比人类更诚实的 AI 员工** |
| 承诺 | 永不出错 (不可实现) | **幻觉率降低 80%，主动承认不确定** |
| 变现 | Token 计费 (薄利) | **SaaS 订阅 ¥99/月 (厚利)** |
| 竞品 | DeepSeek API | **人类员工 / 外包** |

**可行因为：**
1. **多模型防幻觉已验证可行** — Jury 1,421 + Debate 978 + Memory 1,252 = 3,651 LOC 现有代码
2. **诚实 = 壁垒** — 竞品宁愿编造也不承认不知道，Dragon 反其道而行
3. **SaaS 模型远超 Token 模型** — 1万用户 Token 收入 ¥7,380/月 vs SaaS 订阅 ¥800,000/月 (100x 差距)
4. **硬件成本 1/50** — 消费级显卡 vs 企业级 GPU

**风险与缓解：**
- "零幻觉"不可实现 → **改为"比人类诚实"，可量化验证**
- 用户可能不喜欢"我不知道" → **标注置信度，给最佳推测，降低预期**
- 多模型调用增加延迟 → **并行调用 + 流式输出**

**核心建议：**
> **最好的 AI 不是从不出错的 AI，而是知道自己会出错、并主动告诉你的 AI。**
>
> 卖"诚实"比卖"完美"更可持续——因为诚实可以做得到。
