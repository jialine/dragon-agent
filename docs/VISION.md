# Dragon Agent — 会承认不知道的 AI 员工

> **定位**：不是"零幻觉"，而是"比人类更诚实地承认不知道"  
> **核心承诺**：幻觉率降低 80% · 每句话可追溯 · 不确定时拒绝编造

## 0. 可行性前置验证

### 0.1 为什么"零幻觉"不可行

| 幻觉源 | 可否消除 | 原因 |
|--------|:--:|------|
| 训练数据盲区 | ❌ | 所有模型共享同样的知识边界 |
| 系统性偏见 | ❌ | 同源训练数据导致群体错误 |
| 主观问题 | ❌ | "最好的语言"没有客观答案 |
| 时效信息 | ⚠️ | 可通过 Web Search 缓解 |
| 推理链断裂 | ⚠️ | 多模型审查可减少但不可消除 |
| 概率采样 | ✅ | 多模型投票 + 低温度可消除 |

> **结论：物理上不可能达到 0% 幻觉率。但可以做到比单模型好 4-5 倍。**

## 2. 技术架构：六层防幻觉

```
User Question
    │
    ▼
┌─────────────────────────────────────────────┐
│ L1: 路由分类 (0.8B Router) ✅                 │
│   事实型/观点型/计算型 → 不同处理策略          │
├─────────────────────────────────────────────┤
│ L2: 知识检索 (ChromaDB + Web) ✅             │
│   检索相关知识 → 作为陪审团上下文              │
├─────────────────────────────────────────────┤
│ L3: 多模型陪审团 (Jury) ✅ 1,421 LOC         │
│   3 模型独立回答 → 投票 → 标记分歧            │
├─────────────────────────────────────────────┤
│ L4: 交叉辩论 (Debate) ✅ 978 LOC             │
│   模型互相审查 → 指出矛盾 → 修正              │
├─────────────────────────────────────────────┤
│ L5: 事实核查 (FactChecker) 🔜 需新建          │
│   逐条验证 → 置信度 → 来源链接                │
│   工具: 知识库 + Web Search + 计算验证        │
├─────────────────────────────────────────────┤
│ L6: 共识输出 (Consensus) 🔜 需新建            │
│   多数共识 → 直接输出 + [来源][置信度]          │
│   分歧标记 → "模型 A 认为 X，B 认为 Y"          │
│   置信度低 → "我需要确认…目前最佳推测是…"       │
└─────────────────────────────────────────────┘
```

### 输出格式示例

```
✅ 高置信度 (>85%):
  "光合作用将光能转化为化学能。[来源: Campbell Biology §10.2] [置信度: 94%]"

⚠️ 中等置信度 (60-85%):
  "2026年AI市场规模约$200B。⚠️此数据基于2025年报告外推。[来源: Gartner 2025] [置信度: 72%]"

❌ 低置信度 (<60%):
  "我不确定。模型A认为X，模型B认为Y。建议查阅: [链接1][链接2]"
```

## 5. 下一步：4 周可达

### Week 1-2: FactChecker

```
输入: 陪审团答案 + 分歧点
输出: 
  - 每条声明的事实核查结果
  - 知识库匹配度
  - Web Search 验证状态
  - 置信度分数 (0-100%)
```

### Week 3-4: Consensus

```
输入: 核查后的多模型答案
输出:
  - 共识部分 → 直接输出 + 来源标注
  - 分歧部分 → "模型在以下点存在分歧:…"
  - 低置信度 → "我需要更多信息才能回答"
```

