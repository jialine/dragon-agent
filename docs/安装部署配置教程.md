# Dragon Agent 🐉 安装部署配置教程

> 可自我进化的 AI Agent 框架 — 工具系统 · 技能引擎 · 工作流编排 · 多平台网关

---

## 一、系统要求

| 项目 | 最低要求 |
|------|----------|
| Python | ≥ 3.11 |
| 系统 | Linux / macOS / Windows(WSL) |
| 内存 | ≥ 2GB |
| 磁盘 | ≥ 1GB |
| 网络 | 需要访问 andlapi.cn（API 代理） |

## 二、一键安装（推荐）

```bash
curl -fsSL https://gitee.com/jialine/dragon-agent/raw/main/install.sh | bash
```

支持参数：

```bash
# 指定安装目录
curl -fsSL <url> | bash -s -- --dir /opt/dragon-agent

# 指定分支
curl -fsSL <url> | bash -s -- --branch dev

# 跳过测试
curl -fsSL <url> | bash -s -- --skip-test
```

安装过程 5 步：
1. 检查系统（Python 版本 + git）
2. 克隆代码（优先 Gitee，回退 GitHub）
3. 安装 Python 依赖
4. 生成默认配置文件
5. 运行测试验证

## 三、手动安装

```bash
# 1. 克隆仓库
git clone https://gitee.com/jialine/dragon-agent.git
cd dragon-agent

# 2. 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt
pip install -e .

# 4. 配置
cp config.example.yaml config.yaml
# 编辑 config.yaml → 填入 API 密钥
```

## 四、CLI 命令行配置（零手动改文件）

安装后，用 `dragon setup` 交互式配置，不需要手改 YAML：

### 4.1 交互式初始化

```bash
source .venv/bin/activate

# 完整交互式配置向导
dragon setup

# 仅配置飞书
dragon setup --feishu

# 仅配置 API 密钥
dragon setup --providers

# 非交互模式（从环境变量读）
dragon setup --quick
```

### 4.2 模型切换

```bash
# 交互式选择模型和供应商
dragon model

# 直接指定模型
dragon model deepseek-v4-pro
dragon model qwen-max
dragon model gpt-4o
```

### 4.3 配置管理

```bash
# 查看当前配置
dragon config show

# 查看所有配置
dragon config show --all

# 读写单个配置项
dragon config dispatch.global_api.model          # 读
dragon config set dispatch.global_api.model qwen-max  # 写

# 配置文件路径
dragon config path

# 验证配置
dragon config validate

# 从模板初始化新配置
dragon config init --output my-config.yaml
```

### 4.4 诊断检查

```bash
# 运行全面诊断
dragon doctor

# 检查所有组件：模型、网关、工具、内存
dragon doctor --all
```

## 五、核心配置（config.yaml）

### 4.1 LLM 模型

```yaml
dispatch:
  global_api:
    model: deepseek-v4-pro          # 模型名
    base_url: https://api.andlapi.cn/v1
    api_key: "sk-你的API密钥"
    api_key_env: DRAGON_API_KEY      # 也可用环境变量
    max_retries: 2
    timeout_secs: 300
```

支持模型：`deepseek-v4-pro` / `deepseek-chat` / `qwen-max` / `gpt-4o` 等。

### 4.2 Agent 行为

```yaml
agent:
  max_turns: 90                     # 单次对话最大轮数
```

### 4.3 行业 System Prompt

```yaml
dispatch:
  industries:
    general:
      system_prompt: "你是 Dragon Agent..."
    finance:
      system_prompt: "你是一位资深金融分析师..."
    medical:
      system_prompt: "你是一位医学顾问..."
```

### 4.4 飞书网关

```yaml
gateway:
  enabled: true
  port: 8781
  platforms:
    feishu:
      enabled: true
      app_id: "cli_xxxxxxxxxxxxxxxx"
      app_secret: "你的飞书AppSecret"
      domain: feishu              # feishu | lark
```

获取飞书凭证：
1. 打开 [飞书开发者后台](https://open.feishu.cn/app)
2. 创建企业自建应用
3. 开通「接收消息」权限
4. 复制 App ID 和 App Secret
5. 配置事件订阅（请求网址：`http://你的服务器IP:8781/feishu/event`）

### 4.5 本地路由模型（可选）

```yaml
router:
  enabled: false                    # 默认关闭
  model_path: /path/to/Qwen2.5-1.5B-Q4_K_M.gguf
  n_ctx: 2048
```

用于行业分类路由，可降低 API 成本。

### 4.6 记忆知识库（可选）

```yaml
memory:
  persist_dir: dragon_data/vectordb
  embedding_model: BAAI/bge-small-zh-v1.5
  search_top_k: 5
```

## 五、启动运行

### 5.1 CLI 模式

```bash
source .venv/bin/activate
python dragon_agent_loop.py
```

交互式对话，支持所有内置工具。

### 5.2 飞书网关上云

#### 前台运行（调试）

```bash
source .venv/bin/activate
export FEISHU_APP_ID=cli_xxx
export FEISHU_APP_SECRET=xxx
python -m dragon.gateway.cli --feishu --port 8781
```

#### 后台运行（生产）

```bash
nohup bash -c 'source .venv/bin/activate && python -m dragon.gateway.cli --feishu --port 8781' \
  > /var/log/dragon-gateway.log 2>&1 &

# 或使用 systemd（推荐）
sudo tee /etc/systemd/system/dragon-gateway.service << 'EOF'
[Unit]
Description=Dragon Agent Gateway
After=network.target

[Service]
Type=simple
User=jialine
WorkingDirectory=/home/jialine/dragon-agent
Environment="FEISHU_APP_ID=cli_xxx"
Environment="FEISHU_APP_SECRET=xxx"
ExecStart=/home/jialine/dragon-agent/.venv/bin/python -m dragon.gateway.cli --feishu --port 8781
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable dragon-gateway
sudo systemctl start dragon-gateway
```

### 5.3 Docker 部署

```bash
# 构建
docker build -t dragon-agent .

# 运行
docker run -d \
  --name dragon-agent \
  -p 8781:8781 \
  -e FEISHU_APP_ID=cli_xxx \
  -e FEISHU_APP_SECRET=xxx \
  -v $(pwd)/config.yaml:/app/config.yaml \
  dragon-agent
```

## 六、Drama Studio WebUI

短剧制作可视化界面，5 个面板：剧本 → 角色 → 分镜 → 修复 → 视频

```bash
cd webui
source ../.venv/bin/activate
pip install flask              # 依赖
python app.py                  # 默认 5000 端口
```

访问 `http://服务器IP:5000`

### 视频生成配置

Drama Studio 通过 `andlapi.cn` 调用 DashScope 视频生成：

| 模型 | 类型 | 用途 |
|------|------|------|
| `happyhorse-1.1-t2v` | 文生视频 | 无需参考图 |
| `happyhorse-1.1-r2v` | 图生视频 | 需角色参考图 OSS URL |

API Key 配置：环境变量 `DRAGON_API_KEY` 或 `.env` 文件。

## 八、常见问题

### Q: 安装后无法启动？
```bash
# 检查 Python 版本
python3 --version          # 需要 ≥ 3.11

# 检查虚拟环境
source .venv/bin/activate
pip list | grep dragon
```

### Q: 飞书收不到消息？
1. 确认飞书应用已发布并开通「接收消息」权限
2. 确认事件订阅 URL 可公网访问
3. 查看日志：`tail -f /var/log/dragon-gateway.log`

### Q: 视频生成失败？
```bash
# 检查 API Key
echo $DRAGON_API_KEY

# 测试 API 连通性
curl -s -H "Authorization: Bearer $DRAGON_API_KEY" \
  https://api.andlapi.cn/v1/models
```

### Q: 修改代码后不生效？
```bash
# 清除 Python 缓存
find . -type d -name __pycache__ -exec rm -rf {} + 2>/dev/null
find . -name "*.pyc" -delete

# 重启服务
pkill -f "gateway.cli" && sleep 2
source .venv/bin/activate
python -m dragon.gateway.cli --feishu --port 8781 &
```
