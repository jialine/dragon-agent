# Dragon Agent — 功能缺口分析

> 现有代码: 35,463 LOC / 78 文件 / 42 模块 | 已完成 21/33 功能 (64%)

## P0：核心缺失 — 产品不可用 (4 项)

这些不补，产品核心承诺"诚实 AI"无法兑现。

### 1. 🔴 Fact Checker (事实核查引擎) — 0 LOC

**为什么是 P0**：Jury/Debate 发现了分歧，但没有验证"谁对谁错"的机制。

```
输入: 陪审团输出 + 分歧点
处理:
  1. 提取事实性声明 (NER + 关系抽取)
  2. 知识库检索 → 匹配现有知识
  3. Web Search → 查实时信息
  4. 计算验证 → 数学/逻辑自动核验
  5. 置信度评分 → 综合判断
输出: {claim: str, verified: bool, confidence: float, source: str}
```

**关键难点**：
- 主观声明无法验证（需标记为"观点"而非"事实"）
- 知识库覆盖度有限（初始准确率可能只有 60-70%）

**预估工作量**：2 周 / ~1,500 LOC

---

### 2. 🔴 Consensus (共识输出引擎) — 0 LOC

**为什么是 P0**：没有它，Jury 的产出无法变成用户可理解的结果。

```
输入: 核查后的多模型答案 + 置信度
输出:
  - 高一致性 (>85%): 直接输出 + 来源标注
  - 中等 (60-85%): 输出 + ⚠️标记 + 替代观点
  - 低一致性 (<60%): "我不确定，以下是各方观点…"
  - 分歧报告: "模型A认为X，B认为Y，C弃权"
```

**关键难点**：
- 语义等价判断（不同表述但相同意思）
- "我不知道"的频率控制（太多影响体验）

**预估工作量**：1.5 周 / ~1,200 LOC

---

### 3. 🔴 Source Attribution (来源标注引擎) — 0 LOC

**为什么是 P0**："每句话可追溯"是差异化核心，没有来源标注等于没有信任。

```
每句输出必须附带:
  [来源] — 知识库文档 / 网页链接 / 模型推理
  [置信度] — 0-100%
  [验证状态] — ✅已验证 / ⚠️未验证 / ❌存疑
```

**预估工作量**：1 周 / ~600 LOC (依赖 FactChecker)

---

### 4. 🔴 Hallucination Metrics (幻觉率追踪) — 0 LOC

**为什么是 P0**："幻觉率降低 80%" 必须有数据支撑，否则是虚假宣传。

```
基准测试套件:
  - TruthfulQA (事实准确性)
  - HaluEval (幻觉检测)
  - 自建中文基准 (200 题)
  - 每次对话自动抽样评分
  - 仪表板: 幻觉率趋势图
```

**预估工作量**：1 周 / ~800 LOC + 测试数据

## P1：产品化必需 — 不可商用 (4 项)

没有这些，用户没法注册、没法付费、没法管理 Key。

### 5. 🟡 Auth (用户认证) — 0 LOC

```
必需:
  - 注册 (邮箱/手机)
  - 登录 (JWT + refresh token)
  - 密码重置
  - OAuth (微信/GitHub — 中国市场必需)
  - 角色: user / admin
```

**预估工作量**：1.5 周 / ~1,000 LOC (FastAPI + JWT)

---

### 6. 🟡 Billing (计费系统) — 0 LOC

```
必需:
  - 订阅管理 (Free/Pro/Team/Enterprise)
  - 支付集成 (支付宝/微信支付 — 中国市场)
  - 发票管理
  - 用量配额 + 超额提醒
  - 试用期 (7天免费)
```

**预估工作量**：2 周 / ~1,500 LOC + 支付 API 对接

---

### 7. 🟡 API Key Management — 0 LOC

```
必需:
  - Key 生成 / 撤销 / 轮换
  - 用量配额
  - 速率限制 (已有 rate_limiter 631 LOC，需接入)
  - 使用统计仪表板
```

**预估工作量**：1 周 / ~800 LOC (部分复用 rate_limiter + usage_pricing)

---

### 8. 🟡 Confidence Calibration (置信度校准) — 0 LOC

```
问题: 模型说"95% 置信度"，但实际只有 70% 准确
解决: 
  - 校准数据集 (已知答案的问题)
  - Platt Scaling / Isotonic Regression
  - 自动调整置信度使其与实际准确率匹配
```

**预估工作量**：1 周 / ~600 LOC

- ❌ 无计费 (免费内测)
