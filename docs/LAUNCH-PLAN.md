# Dragon Agent 快速推广方案（预算 5,000 元）

> **定位**：中国首款「诚实 AI」编辑器 — 多模型辩论 + 事实核查 + 来源标注
> **目标**：4 周内获取 500 种子用户，验证 PMF（Product-Market Fit）
> **预算**：¥5,000（现金支出，不含人力）

## 一、为什么 5,000 元够用：核心论证

### 1.1 我们卖的不是广告，是差异化

AI 工具市场红海，但存在结构性空白：**所有产品都在比「快」和「便宜」，没人在比「可信」**。

| 竞品 | 核心卖点 | 用户痛点 |
|------|---------|---------|
| Kimi/ChatGPT | 快、长文本 | 幻觉严重，不敢信 |
| 文心一言/通义 | 免费、生态 | 答案中庸，"都行" |
| DeepSeek | 便宜、开源 | 推理强但事实性差 |
| **Dragon** | **可验证的真相** | **敢用、敢信、敢引用** |

**关键洞察**：AI 用户正在从「尝鲜期」进入「信任期」。第一批用户已经经历了足够的 AI 幻觉，开始主动寻找更可靠的方案。Dragon 正好卡在这个时间窗口。

### 1.2 5,000 元能做什么

| 策略 | 预算 | 预期覆盖 | 预期转化 |
|------|:--:|------|:--:|
| KOL 种子内容 | ¥2,000 | 50,000+ 曝光 | 100-200 注册 |
| 知乎/小红书精准投放 | ¥1,500 | 30,000+ 曝光 | 80-150 注册 |
| 社群裂变 + 邀请制 | ¥500 | 病毒传播 | 200-400 注册 |
| 工具型内容（SEO长尾） | ¥800 | 持续流量 | 50-100 注册 |
| 应急预备金 | ¥200 | — | — |
| **合计** | **¥5,000** | **80,000+** | **430-850** |

**为什么 ROI 能打正**：① 差异化足够尖锐，转化率高于行业均值；② 邀请制制造稀缺感；③ 产品本身有自传播属性（每句话带来源标注 = 天然品牌露出）。

## 二、四周执行计划

### Week 1：内容基建（¥1,800）

**目标**：建立核心内容资产，让后续推广有东西可引。

| 动作 | 预算 | 产出 |
|------|:--:|------|
| 录制「Dragon vs ChatGPT 事实核查对决」视频（3 期） | ¥800 | 3 条 3-5min 对比视频 |
| 知乎长文「AI 幻觉率实测：6 款产品横向对比」 | ¥300 | 1 篇深度评测（含数据图表） |
| 小红书图文「AI 说的每一句话，我都帮你查了一遍」 | ¥200 | 5 条图文笔记 |
| GitHub README 中英文优化 + 产品 landing page | ¥0 | 开源项目页 |
| 飞书/微信社群搭建（种子用户群） | ¥500 | 2 个 200 人群 + 邀请海报 |

**论证**：内容营销是 AI 工具的最优获客渠道。目标用户（开发者、AI 重度用户、研究者）高度集中在知乎/GitHub/飞书，内容驱动决策。对比视频是最好的产品 demo — **不用解释，一眼看出差异**。

### Week 2：KOL 冷启动（¥2,000）

**目标**：借助已有信任关系，快速获取第一批高质量用户。

| 动作 | 预算 | 产出 |
|------|:--:|------|
| 联系 3-5 位 AI/科技类知乎大 V，寄送内测邀请码 + 定制测评 | ¥1,200 | 2-3 篇自然测评 |
| B站/小红书 AI 博主合作（产品置换，无需现金） | ¥0 | 1-2 条开箱视频 |
| 技术社区发帖（V2EX、掘金、SegmentFault） | ¥0 | 5 篇技术解析 |
| 第一批内测用户定向邀请（GitHub star 前 100 名） | ¥0 | 100 个种子用户 |
| 用户反馈激励机制（最佳 bug report 奖 ¥200） | ¥300 | 50+ 条有效反馈 |
| 预备金 | ¥500 | — |

**论证**：KOL 不要找头部（¥10,000+ 且转化率低），找 5K-50K 粉丝的「腰部创作者」。他们：
- 接单意愿强（¥300-500/篇）
- 粉丝信任度高（转化率 3-5% vs 头部 0.5%）
- 内容真实感强（不像广告）

**重点**：要求 KOL 必须真实使用产品，给出「用了 Dragon 才发现之前 ChatGPT 在胡说的 3 个例子」。**真实案例的传播力是软文的 10 倍**。

| 动作 | 预算 | 产出 |

## 四、为什么这个方案可行（风险与对策）

### 4.1 主要风险

| 风险 | 概率 | 影响 | 对策 |
|------|:--:|------|------|
| 产品 bug 多，用户流失 | 中 | 高 | Week 0 跑完 P0+P1 核心流程测试，确保 MVP 稳定 |
| KOL 不接单 | 中 | 中 | 备选 10+ KOL，优先产品置换（零现金） |
| 竞品快速跟进「事实核查」 | 低 | 高 | 我们有先发优势 + 多模型陪审团（壁垒更高） |
| 用户对「诚实 AI」无感 | 低 | 致命 | 如果此假设错误，整个产品定位需重新思考 |

### 4.2 为什么不是「烧钱买量」

- 买量 CPI（每安装成本）在 AI 赛道已达 ¥15-30，¥5,000 只能买 150-300 个下载，且次日留存通常 <20%
- Dragon 是**高认知门槛产品** — 用户需要理解「多模型辩论」「事实核查」才愿意付费。买量来的用户 80% 会秒删
- **内容 + 社区驱动增长**对于差异化产品更有效：用户先看到对比 → 产生好奇 → 主动搜索 → 深度使用

### 4.3 核心假设

这个方案建立在 3 个假设上，都需要 Week 1-2 验证：

1. **「AI 幻觉」是真实痛点**，用户愿意为「可信」付费 — 验证：邀请码领取率 > 30%
2. **多模型辩论产生明显更好的结果** — 验证：A/B 测试留存率 vs 单模型
3. **来源标注是传播钩子** — 验证：用户主动截图分享频率

**如果任意假设失败：立即停止推广，回炉产品。**
