## 一、画面描述

### 1.1 开场画面（0:00–0:03）

黑色画面上，雨是横着抽过来的。

镜头极其缓慢地下摇——海水浮现。北大西洋的浪是黑的。六米涌浪像移动的山脉。

然后灯光出现。三百盏灯。

方舟-0 从暴风雨中浮出。它不像船，像被焊在石油平台上的飞碟。七个甲板层叠堆叠，每层亮着不同色温的灯光——底层血红应急灯，中层骨白无影灯，顶层冷蓝航行灯。整艘船像一块漂浮的电路板，被雨幕切割成无数碎片。

**画外信息（字幕叠加，画面左下角，字体：等宽军事风格）：**

> 方舟-0 · ARK-0
> IV级生物隔离 · 实验科研船
> 距纽约港 100 海里
> 坐标：39°27'N, 72°08'W

**镜头运动**：极缓推轨，大远景推向船体。3秒内完成。

---

### 1.2 船体细节（0:03–0:07）

镜头持续推进，方舟-0 结构逐层清晰：

- **直升机甲板**：船尾最顶层，目前空荡。琥珀色甲板灯在暴雨中形成一圈朦胧的橙色光晕。
- **起重机阵列**：四台龙门起重机沿左舷排列，吊臂全部向内折叠——像四只跪着的螳螂。
- **球形穹顶**：船体中段最显眼的结构——直径约30米的白色球体，表面是六边形蜂窝面板。雨水打在穹顶上会瞬间滑走，形成一层持续变化的流动薄膜——疏水涂层在起作用。穹顶内部透出幽蓝色的微光，像一颗摘下来的鲸鱼眼珠。
- **通风塔**：船艏两根25米高的通风塔，顶部红色航空障碍灯以3秒间隔脉冲——每闪一次，塔身在水面上的倒影就被浪撕碎一次。塔身表面布满铆钉和检修走道，走道上此刻无人。
- **吃水线**：船体被浪拍到的时候，吃水线以下露出一排暗红色警示灯——"RESTRICTED ZONE"字样在水线下若隐若现。

**镜头运动**：横移推轨，从左舷到右舷，建立船体空间关系。

---

### 1.3 海面视角（0:07–0:09）

镜头从海面高度仰拍。

巨大的涌浪涌入前景——浪峰泡沫在黑暗中泛着幽绿色的磷光。浪谷下降时，方舟-0 短暂被海水吞没，只露出球形穹顶和通风塔顶端，像一头鲸鱼只露出背鳍。

**关键道具进入画面（右下方）**：一个橙红色救生圈，被浪卷着漂过。救生圈上印着黑色字："方舟-0 — 最高生物安全级别 — 未经许可不得靠近"。

救生圈随即被另一道浪拍翻，消失在黑色的海水里。

---

### 1.4 直升机降临（0:09–0:15）

**0:09–0:10**

画外音效先进入——旋翼声从远处压来，低频递增。

仰拍镜头：雨幕中，一架军用直升机破雾而出。UH-60M 黑鹰，哑光黑色机身，编号 HX-07。机头探照灯穿透雨幕形成锥形光柱，在方舟-0甲板上扫过。

**0:10–0:12**

镜头切至顶部视角，正对着直升机甲板。

黑鹰在空中悬停2秒——旋翼下洗气流把甲板上的积雨炸成一圈白色水环，向四周扩散。甲板边缘的指示灯因为气流剧烈抖动。

**0:12–0:14**

直升机开始下降。不是缓慢着陆——是战术降落（tactical drop），机身最后一米是直接砸下来的。起落架触甲板的瞬间，积水猛烈溅射，金属撞击声被旋翼噪音吞没。

甲板上十几根固定缆绳被下洗气流吹得疯狂摆动。

**0:14–0:15**

旋翼转速开始下降。画面切近——直升机舱门侧面的圆形舷窗。

舷窗内透出暗绿色微光——夜视仪照明模式。窗内隐约有人影在移动。一只手从内侧按在玻璃上——戴黑色战术手套——

——镜头直接切黑。

## 二、音效设计

### 2.1 音效分层

| 音轨 | 内容 | 起止时间 | 动态 |
|------|------|----------|------|
| L1 环境底噪 | 海涌低频（20–60Hz持续） | 0:00–0:15 | 稳定 |
| L2 风噪 | 50–70节暴风，阵风型 | 0:00–0:15 | 0:03峰值，0:08衰减 |
| L3 船体 | 28Hz引擎嗡鸣（方舟反应堆基频） | 0:00–0:15 | 持续，极缓 |
| L4 浪击 | 浪拍船体的金属回响 | 0:02/0:06/0:08 | 间隔4–6秒 |
| L5 旋翼 | 黑鹰桨叶，120–150Hz | 0:09–0:15 | 渐强，0:12峰值 |
| L6 着舰 | 金属撞击+承重结构受力 | 0:13–0:14 | 尖锐 |
| L7 舱门 | 液压舱门滑开 | 0:14–0:15 | 清晰机械音 |
| L8 军靴 | 踏上甲板积水 | 0:15末尾 | 清脆 |

### 2.2 声音情绪曲线

- **0:00–0:08**：不安。只靠海涌和浪击，留白让人等。
- **0:09–0:12**——紧张。旋翼变成一切。下洗气流声被故意放大，让它有压迫感。
- **0:13–0:14**——落地。金属撞击声要响——这不是客机，是军用机。要让人感觉到"有什么东西被送来了"。
- **0:14–0:15**——最后的安静。旋翼减速，舱门——
- **切黑后**：所有声音0.3秒内消退。只剩海涌低频延0.5秒——然后全静。因为黑场之后，观众需要一秒钟呼吸。

## 三、调色与视觉参考

### 3.1 调色方向

| 参数 | 数值 |
|------|------|
| 整体色温 | 4200K（偏冷） |
| 饱和度 | 去饱和60% |
| 唯一暖色 | 琥珀色甲板灯 + 红色应急灯 |
| 高光 | 青色偏移（+15 teal） |
| 暗部 | 压至5% IRE（不完全黑） |
| 雾/雨 | 中灰半透明层，颗粒感 |
| 磷光 | 暗部加微量绿色（仅浪尖） |

### 3.2 视觉参考片目

| 参考作品 | 借鉴方向 |
|----------|----------|
| 《银翼杀手2049》Sea Wall场景 | 雨中海景的灰蓝色调、雾气质感 |
| 《降临》直升机场景 | 军用直升机在特殊环境中的重量感 |
| 《蝙蝠侠》（2022）开场 | 暴风雨夜的潮湿质感、光源在雨中的散射方式 |
| 《深海浩劫》钻井平台远景 | 工业平台在夜间海面上的光污染效果 |
| 《三体》奈飞版"审判日号" | 巨型科研船的外观比例参考 |

### 3.3 灯光方针

- **方舟-0 整体**不打主光，让它作为光源出现
- **甲板灯**琥珀色，雨中的光晕要大、要柔
- **球形穹顶**幽蓝内透，不加外部光源——它从内部发光
- **直升机探照灯**冷白，切过雨幕时要有明显的散射锥
- **应急灯**血红，每3秒一闪（与通风塔同步）
