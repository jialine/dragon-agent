# 使用手册

## 一、WebUI（Drama Studio）

启动后访问 `http://<IP>:5000/`。

### 核心功能
- **项目管理**：创建/切换短剧项目
- **剧本生成**：两阶段生成（大纲 → 分集剧本）
- **角色管理**：角色四视图生成、OSS 上传、`portrait_oss` 关联
- **分镜管理**：按集切换、故事板卡片、批量优化提示词
- **视频提交**：单镜/整集提交，后台异步轮询下载

### 视频提交 API

```bash
# 提交单镜（project_id 必传）
curl -X POST http://127.0.0.1:5000/api/video/submit \
  -H 'Content-Type: application/json' \
  -d '{"shot_id": 206, "project_id": 25}'

# ⚠️ 字段名是 ref_image（单数），不是 ref_images
curl -X POST http://127.0.0.1:5000/api/video/submit \
  -H 'Content-Type: application/json' \
  -d '{"shot_id": 327, "project_id": 30, "ref_image": "https://oss.../portrait.png"}'
```

## 二、脚本 CLI

### gen_video.py（视频生成核心）

```bash
cd scripts

# T2V（纯场景/空镜）
python3 gen_video.py "暴雨夜，城市天际线俯拍，霓虹灯光，电影级16:9" \
  --model happyhorse-1.1-t2v --size 1920*1080 --duration 8

# R2V（有命名角色，必须挂参考图）
python3 gen_video.py "银背骑着虎鲸王破浪而出" \
  --model happyhorse-1.1-r2v \
  --ref-image "https://oss.../银背_portrait.png"

# 异步提交（仅提交不等待，推荐 WebUI/Flask 内调用）
python3 gen_video.py "提示词" --submit-only

# prompt 内嵌 [url] 自动提取参考图
python3 gen_video.py '银背 [https://oss.../portrait.png] 骑着虎鲸王' \
  --model happyhorse-1.1-r2v
```

## 三、模型选型铁律

| 镜头类型 | 模型 | 参考图 |
|---------|------|--------|
| **有命名角色**（单人/多人/中景/特写/同框） | `happyhorse-1.1-r2v` | 必填 OSS URL |
| 纯空镜/场景建立 | `happyhorse-1.1-t2v` | null |
| 显微/抽象/特效 | `happyhorse-1.1-t2v` | null |

> ⚠️ 只要 prompt 出现命名角色，无论镜头距离/动作/角色数量，一律 R2V。
> ⚠️ 禁用 wan2.7 系列（会静默失败）。

## 四、提示词规则

1. **中文**，≤ 80 字（HappyHorse 轻量模型，长描述跑偏）
2. 保留：主体、环境、天气、光影、色调、画幅
3. 删除：运镜描述、音效分层、技术参数
4. 片尾字幕不要写具体中文文字（模型渲染会乱码）

```
✅ 正确（65字）：暴雨夜，黑暗未来都市天际线俯拍，霓虹灯光映在湿漉漉的街道上，电影级16:9，超写实，暗黑科幻氛围
❌ 错误：英文 prompt / 300+字长描述
```

## 五、参考图管理

### SignOSS 上传（小文件 <10MB）

```bash
curl -sk -X POST "https://api.andlapi.cn/signoss/upload" \
  -H "X-API-Key: $SIGNOSS_API_KEY" \
  -F "file=@portrait.png;filename=char_name.png"
```

> ⚠️ 认证头是 `X-API-Key`，不是 `Bearer`。

## 六、场记命名规范

```
{项目}/EP{集}_S{镜}_V{shot_id}_T{场次}_s{种子}.mp4
```

示例：`猩族纪元_觉醒之战/EP01_S01_V188_T02_s428391.mp4`

## 七、审查规避（军事/暴力）

战斗场景触发 DashScope 绿网审查。用中性措辞替代直接暴力：
- 「杀死、攻击」→「消失在画面暗处」「低沉咆哮」
- 「撞碎玻璃」→「冲入舰桥」
- 「血雾」→「水雾」

详见 `short-drama-video-generation` 技能的 Green Net 替换表。
