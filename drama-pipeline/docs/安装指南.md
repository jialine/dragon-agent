# 安装指南

## 环境要求

| 依赖 | 版本 | 必需 | 说明 |
|------|------|------|------|
| Python | ≥ 3.8（推荐 3.11） | ✅ | 运行脚本 + WebUI |
| git | 任意 | ⚠️ | 仅 `--from-git` 模式需要 |
| ffmpeg | 任意 | ⚠️ | 合成/片头阶段需要 |
| edge-tts | ≥ 6.1 | ⚠️ | 配音阶段需要 |
| 网络 | 可访问 api.andlapi.cn | ✅ | LLM + 视频生成 |

## 一键安装

```bash
# 方式一：本地包安装（推荐，开箱即用）
./install.sh

# 方式二：指定安装目录
./install.sh --dir /opt/dragon-drama

# 方式三：免交互（CI/自动化）
./install.sh --yes --api-key sk-xxx --port 5000

# 方式四：从 git 仓库拉取
./install.sh --from-git https://gitee.com/xxx/dragon-drama-pipeline.git
```

## 安装做了什么

1. **预检**：检查 python3 / git / ffmpeg
2. **部署代码**：复制到 `~/dragon-drama`（或 `--dir` 指定）
3. **依赖**：创建 `.venv` 虚拟环境，`pip install -r requirements.txt`
4. **配置**：从模板生成 `config.yaml` + `.env`（已存在的保留不覆盖）
5. **数据目录**：创建 `assets/` `output/` `dragon_data/`
6. **启动 WebUI**：后台 `nohup` 启动，日志在 `/tmp/dragon-drama-webui.log`
7. **健康检查**：curl 探测 5000 端口

## 配置 API Key

安装后必须填入 andlapi API Key（LLM + 视频生成统一用）：

```bash
vi ~/dragon-drama/.env
# DRAGON_API_KEY=sk-你的真实Key
```

Key 获取：https://api.andlapi.cn

Key 读取优先级（`gen_video.py` / `drama_common.py` 一致）：
1. 环境变量 `DRAGON_API_KEY`
2. `config.yaml` → `dispatch.global_api.api_key`
3. `config.yaml` → `api_key_env` 指向的环境变量（如 `DEEPSEEK_API_KEY`）

## 常见问题

### Q: 端口被占用
```bash
./install.sh --port 5001
```

### Q: venv 创建失败
脚本自动回退到系统级 `pip3 --break-system-packages`。或手动：
```bash
python3 -m pip install --user -r requirements.txt
```

### Q: WebUI 启动后无响应
```bash
tail -f /tmp/dragon-drama-webui.log
```

### Q: 视频提交报 Invalid token
`.env` 里的 `DRAGON_API_KEY` 是占位符，未填真实 Key。

### Q: 需要 ffmpeg 但无 sudo 权限
使用静态编译版（无需安装）：
```bash
wget https://johnvansickle.com/ffmpeg/releases/ffmpeg-release-amd64-static.tar.xz
tar -xf ffmpeg-release-amd64-static.tar.xz
# 把解压出的 ffmpeg 加入 PATH
```

### Q: 安装到已有流水线的目录
脚本自动识别，用 rsync 同步代码但**排除** `config.yaml`/`.env`/`drama.db`/`assets`，不丢数据。
