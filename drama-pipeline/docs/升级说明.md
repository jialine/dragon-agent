# 升级说明

## 一键升级

```bash
cd ~/dragon-drama
./upgrade.sh
```

## 三种升级模式

### 1. 默认（git 仓库 / 本地无源）
- 若是 git 仓库 → `git pull --ff-only`
- 否则提示用 `--src` 或 `--from-git`

### 2. 从本地新包覆盖
```bash
./upgrade.sh --src /path/to/new-dragon-drama-pipeline
```

### 3. 从 git 仓库拉取
```bash
./upgrade.sh --from-git https://gitee.com/xxx/dragon-drama-pipeline.git
```

## 升级流程

1. **备份**：`config.yaml` / `.env` / `webui/drama.db` / `assets/` → `.upgrade_backup_时间戳/`
2. **更新代码**：git pull 或 rsync 覆盖（**排除**数据文件）
3. **更新依赖**：`pip install -r requirements.txt`
4. **重启 WebUI**：杀旧进程 → 启动新进程
5. **健康检查**：curl 探测端口

## 数据保护（铁律）

升级时以下文件**绝不覆盖**：

| 文件/目录 | 内容 |
|-----------|------|
| `config.yaml` | 你的配置 |
| `.env` | API Key、飞书凭据 |
| `webui/drama.db` | 项目/分镜/任务数据库 |
| `assets/` | 角色图、视频产物 |

## 回滚

升级失败时：

```bash
# 1. 恢复配置
cp .upgrade_backup_20260813_093000/config.yaml .
cp .upgrade_backup_20260813_093000/.env .

# 2. 恢复数据库
cp .upgrade_backup_20260813_093000/drama.db webui/

# 3. 恢复资产
cp -r .upgrade_backup_20260813_093000/assets/ .

# 4. 重启
./install.sh --yes   # 重新走一遍安装（会保留已有配置）
```

## 版本管理建议

- 代码用 git 管理（`--from-git` 模式），升级 = `git pull`
- 每次大改前手动备份：`cp -r ~/dragon-drama ~/dragon-drama.bak.$(date +%Y%m%d)`
- 关键数据（drama.db）定期 rsync 到 NAS/云

## 卸载

```bash
./uninstall.sh              # 完全卸载（含数据）
./uninstall.sh --keep-data  # 只删代码，保留数据
```
