# 工作流说明

## 五阶段流水线

```
阶段一：编剧（LLM）
  大纲 → 完整故事 → 分集剧本
      ↓
阶段一·五：审核
  单模型审阅 → 汇总修正 → 三模型交叉审阅
      ↓
阶段二：资产
  资源清单提取 → 角色四视图 → 场景画面
      ↓
阶段三：分镜 + 拍摄
  分镜表（模型选型+种子） → 逐镜拍摄（r2v/t2v）
      ↓
阶段四：后期
  片头 → BGM → 字幕 → ffmpeg 合成
      ↓
阶段五：终审
  视觉审核 → 汇总 → 终审结论
```

## 关键配置项（config.yaml）

```yaml
dispatch:
  global_api:
    model: deepseek-v4-pro          # 剧本/审阅（推理模型）
    base_url: https://api.andlapi.cn/v1
    api_key: "sk-xxx"               # 或用环境变量 DRAGON_API_KEY
    api_key_env: DRAGON_API_KEY
    max_retries: 2
    timeout_secs: 300

gateway:
  port: 8781
  system_prompt: ""                 # 全局 system prompt
```

## 模型分工

| 任务 | 模型 | 理由 |
|------|------|------|
| 剧本创作/审阅/文本 | `deepseek-v4-pro` | 深度推理 |
| **分镜表/JSON/结构化输出** | `deepseek-v3.2` | 零推理开销，100% token 有效 |
| 视频生成 | `happyhorse-1.1-r2v` / `happyhorse-1.1-t2v` | 短剧铁律 |

> ⚠️ 推理模型（v4-pro）86% token 被内部推理吃掉，结构化输出必截断。分镜表必须用 v3.2。

## 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `DRAGON_API_KEY` | 空 | andlapi 统一 API Key |
| `DRAMA_MODEL` | `deepseek-v4-pro` | 剧本/审阅模型 |
| `PORT` | `5000` | WebUI 端口 |
| `SIGNOSS_API_KEY` | 空 | SignOSS 参考图上传 Key |
| `SIGNOSS_BASE` | 空 | SignOSS 服务地址 |
